# 팔린아파트

호가 말고, 실제로 팔린 아파트 값. 국토부 실거래 기반 부동산 웹앱. (React + Vite)
(구명: 집한눈 → 실거래 중심으로 정체성이 바뀌며 개명)

지역 범위: **수도권 16개 지역** — 서울 8개 구(강남·서초·송파·용산·마포·성동·노원·강서) + 경기 8개 시·구(과천·분당·하남·광명·평촌·수지·영통·일산)

## 실행

```bash
npm install
npm run dev
```

## 기능

| 페이지 | 경로 | 내용 |
|---|---|---|
| 최근에 팔린 아파트 | `/` | 선택 지역의 실제 계약(매매 3개월 + 전월세 2개월)을 카드로 표시. 아파트 이름·동 검색, 거래유형(실건수)·가격·면적 필터 + 정렬 5종, 30건씩 더보기. 카드에 준공연도·단지/구 평균 대비 ±%·재건축 연한(30년+) 태그. 지역별 향후 가치 전망 카드(실거래 모멘텀·거래량 기반) |

지역 범위(실거래): **서울 25개 구 + 경기 전체 47개 시군구** (`src/data/api.js`의 `REGION_DISTRICTS`).
화성시는 구 신설로 법정동 코드가 4개(남양·송산 41591 / 봉담 41593 / 병점 41595 / 동탄 41597)로 분리되어 있음(실측 확인).
부천시도 3개 구 코드(원미 41192 / 소사 41194 / 오정 41196) 사용.
| 지도 | `/map` | Leaflet(OSM) 지도에 가격 마커 — **데모** (실거래에는 좌표가 없음, 배지 표시) |
| 상세 | `/listing/:id` | 카테고리별 기본 정보, 주변 시세 대비, 향후 가치 전망, 최근 이슈, 인프라, 위치 지도, 주민 리뷰, 36개월 평당가 차트 |
| 시세 | `/market` | 권역 토글 + 지역별 평당가 추이, 전월/전년 대비, 판매 상황, 최근 실거래 테이블 |
| 계산기 | `/calc` | 주담대 한도(LTV 70%·DSR 40%), 월 상환액(3가지 상환방식), 취득세 |

### 카테고리별 상세 항목

- **아파트/빌라**: 면적, 구조(방·욕실), 방향, 준공연월, 층수, 최근 이슈(재건축·리모델링 등), 주민 리뷰(별점), 주변 시세 대비(%), 인프라 태그
- **토지**: 면적, 방향, 유형(지목), 용도지역, 평당가, 주변 시세 대비(%), 최근 이슈, 인프라 태그

### 향후 가치 전망 (규칙 기반)

현재 판매 상황과 물건 요인을 점수화해 4등급(상승 여력 높음 / 완만한 상승 기대 / 보합 전망 / 하방 압력 주의)으로 표시합니다. 산출 로직은 `src/data/mock.js`의 `getOutlook()`:

- **판매 상황**: 구별 3개월·전년 시세 모멘텀, 매매 매물 수, 급매 비중(시세 대비 -5% 이하)
- **물건 요인**: 개발 호재 이슈, 재건축 연한(30년+), 초역세권(도보 7분 이내), 시세 대비 가격 메리트/고평가

근거 요인이 상세 페이지에 +/- 목록으로 함께 표시되며, 투자 권유가 아님을 고지합니다.

### 사진

매물 사진 데이터가 없으므로 사진을 표시하지 않으며, 상세 페이지에 "등록된 사진이
없습니다"를 명시합니다. 실사진 데이터가 확보되면 그때 갤러리를 추가합니다.

## 실거래가 연동 (동작 확인 완료)

시세 페이지의 "최근 실거래" 테이블은 Cloudflare Worker 프록시
(`jiphannun-proxy.nolsoop-games.workers.dev`)를 통해 국토부 실거래가를 실시간 조회합니다.
서울·경기 16개 지역 모두 실데이터 확인 완료 (2026-08-10).

- 프록시 코드: [cloudflare-worker.js](cloudflare-worker.js) v3 — 매매 상세/기본 두 API 상품을
  순서대로 시도, Secret `MOLIT_KEY`는 Encoding/Decoding 키 자동 판별
- 앱 쪽 연동: `src/data/api.js` (시군구 법정동 코드 매핑 + XML 파싱, `cache: 'no-store'`로
  에러 응답의 브라우저 캐시 고착 방지)
- 프록시 연결 실패 시 데모 데이터로 폴백하며 화면에 "데모" 배지와 경고를 표시

시세 페이지에서 실데이터로 동작하는 것:
- **평당가 추이 (14개월)**: 월별 매매 실거래의 평균 평당가. 진행 중인 달은 회색 막대(표본 부족),
  거래 없는 달은 건너뜀. 통계 카드(기준월 평당가·전월/전년 대비·국평 환산·거래량)도 여기서 계산
- **매매 실거래 테이블 (3개월)**, **전월세 실거래 (2개월, 전세/월세 토글)** — 해제 거래 제외
- 매물 목록·상세·급매 비중은 여전히 데모 (화면에 "(데모)" 표기). 전월세는 조회 실패 시
  대체 데모 없이 실패 메시지만 표시

## 데이터

현재는 `src/data/mock.js`의 시드 고정 목데이터입니다(새로고침해도 동일).
실서비스 연동 시 이 파일의 export 시그니처(`listings`, `getPriceSeries`,
`getRecentTrades`)를 유지한 채 내부 구현만 교체하면 됩니다.

- 실거래가: 국토교통부 실거래가 공개시스템 API (공공데이터포털 키 필요)
- 지도: 현재 OpenStreetMap. 한국 지도 품질을 높이려면 카카오맵/네이버지도 SDK로 교체 (API 키 필요)

데이터 출처 고지는 전 페이지 공통 푸터(`App.jsx`)와 시세·상세 페이지 하단에 표시되며,
문구는 `src/data/mock.js`의 `DATA_SOURCE`에서 한 곳으로 관리합니다.

## 주의

계산기는 참고용 단순 모델입니다. 스트레스 DSR, 규제지역별 LTV, 취득세 감면 특례 등은 반영되어 있지 않습니다.
